## Gestor de incidencias (Practica Javadocs & README)
Proyecto que implementa metodos y clases para la manipulacion de incidencias junto a un menu para su filtrado por pantalla  

## Funcionalidades

- Listar todas las incidencias o solo las abiertas.
- Buscar por un texto facilitado.
- Buscar incidencia por un identificador facilitado

## Requisitos

- JDK 25 o compatible.

## Compilación y Ejecución el proyecto;

con maven en el PATH del equipo:
```bash
mvn clean compile exec:java
```
o con el wrapper de maven
```bash
.\mvnw.cmd clean compile exec:java
```
